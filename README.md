# To-Do Ultra

Egy egyszerű, reszponzív és könnyen használható webes teendőlista alkalmazás HTML, CSS és JavaScript alapokon.

## ✨ Funkciók

- Új feladatok hozzáadása
- Feladatok megjelölése késznek
- Feladatok törlése

## 🛠️ Felhasznált technológiák

* **HTML5** – A felület szerkezete
* **CSS3** – Stílusok és reszponzív megjelenés


## 📁 Projekt felépítése

```text
To-Do-Ultra/
├── index.html      # Fő HTML fájl
├── style.css       # Stíluslapok
├── script.js       # Alkalmazás logika
└── README.md       # Dokumentáció
```
